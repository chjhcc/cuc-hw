# 第六章：安全评估实战

## 实验一：OWASP Juice Shop 实战 - Broken Access Control

### 步骤一：查看其他用户的购物篮

先通过查看自己购物篮找到相应路径
![](./1.png)
查看网络请求中，有哪些用户传递的参数，使得当前用户可以查看自己的购物车。
通过查看请求头，发现请求的 URL /rest/basket/6 中，6 可能是用户自己的 ID。
因此可以尝试修改 ID 为其他数字，看是否能够访问到其他的用户购物车信息。
由于自己的用户为新注册的用户，因此可以将 ID 减小，尝试访问之前的用户的购物车信息。
![](./2.png)

### 步骤二：以其他用户身份发布产品评论

相同的思路，需要先尝试使用正常的产品评论的功能。
在以下请求中，我们发现 /rest/products/24/reviews 路径下的 PUT 请求，可以发布产品评论。
其中 24 可能为产品 ID，payload 中 author 字段可能为标识用户的邮箱。message 为评论的消息。

### 步骤四：将其他产品放入另一个用户的购物篮

将物品加入购物篮，发现是/api/BasketItems/下的POST请求
![](./8.png)
其中的basketid就是对应用户

![](./9.png)
